# Kesher (קשר)

אפליקציית היכרויות חינמית בקונספט של Hinge.

- **גילוי**: פרופיל אחד בכל פעם, עם עד 6 תמונות, 3 תשובות לשאלות וכרטיס פרטים (גיל, מגדר, גובה, עיר, סטטוס, מזל, עיסוק, השכלה, עיר הולדת, דת, מה מחפשים, ילדים, שפות והרגלים). לייק לתמונה או לתשובה מסוימת, עם תגובה, או ורד. כפתור X לדילוג.
- **חיפוש וסינון**: חיפוש לפי עיר עם השלמה אוטומטית וכפתורי ערים, ומסך סינון: טווח גילאים (מגיל ועד גיל), סטטוס (רווק/ה, גרוש/ה, פרוד/ה, אלמן/ה, בתהליך גירושין), דת ואמונה וילדים.
- **אהבו אותך**: רשת של מי שעשו לך לייק, עם התגובה שלהם. לייק בחזרה יוצר התאמה.
- **התאמות וצ'אט**: התאמות חדשות, שיחות, ביטול התאמה, דיווח וחסימה.
- **פרופיל**: עריכת כל הפרטים, בחירת שאלות והעלאת עד 6 תמונות.
- **חינם לגמרי**: אין תשלום ואין מנוי.

## מבנה

- **`server/`**: האפליקציה האמיתית: שרת Node, מסד נתונים, הרשמה והעלאת תמונות. הוראות ב-[server/README.md](server/README.md).
  הממשק עצמו נמצא ב-`server/public/` (`app.js`, `style.css`).
- **`index.html`**: גרסת הדגמה בקובץ אחד. זה אותו ממשק בדיוק, אבל במקום השרת יש `demo-src/mock-api.js` שעונה על אותן בקשות בתוך הדפדפן, עם 16 פרופילים מאוירים לדוגמה (`demo-src/sample-data.js`). `app-body.html` הוא אותו תוכן בלי מעטפת ה-HTML.

אחרי שינוי ב-`server/public` או ב-`demo-src` בונים מחדש את ההדגמה:

```bash
python3 build-demo.py
```
