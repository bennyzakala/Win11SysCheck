# Kesher (קשר)

אפליקציית היכרויות בקונספט של Hinge, עם חיפוש לפי עיר.

- **גילוי**: פרופיל אחד בכל פעם, עם תמונות ותשובות לשאלות. לייק לתמונה או לתשובה ספציפית, עם תגובה אופציונלית. כפתור X לדילוג.
- **חיפוש לפי עיר**: שדה חיפוש חופשי עם השלמה אוטומטית, צ'יפים של ערים עם מספר הפרופילים בכל עיר, וסינון גיל.
- **ורד**: ורד אחד לשליחה, כדי לבלוט.
- **אהבו אותך**: מי שעשה לך לייק. לייק בחזרה יוצר התאמה.
- **התאמות**: רשימת שיחות וצ'אט.
- **פרופיל**: עריכת שם, גיל, עיר, עיסוק, תשובות והעלאת תמונות. העיר שלך הופכת לעיר ברירת המחדל בחיפוש.

הפרופילים הם לדוגמה, והנתונים נשמרים ב-localStorage של הדפדפן. אין שרת.

## הרצה

פותחים את `index.html` בדפדפן. `app-body.html` הוא אותו תוכן בלי מעטפת ה-HTML.
